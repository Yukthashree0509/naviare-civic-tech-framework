# Naviare: Civic Tech & Informal Settlement Mapping 📍

> **Transforming informal settlements through data analysis, mobile tech, and sustainable urban frameworks.**

## 🌐 About the Project
Naviare is a youth-led civic technology initiative based in Ramanagara, Karnataka. We leverage data science and field research to map urban infrastructure gaps, clean energy access, and public service requirements, turning ground-level observations into actionable digital frameworks.

## 📊 Core Objectives
- **Baseline Data Collection:** Structuring mobile-friendly surveys for ground mapping.
- **Urban Analytics:** Processing field data to visualize infrastructure needs using Python/Data tools.
- **Sustainable Scaling:** Aligning local solutions with UN Sustainable Development Goal 11 (SDG 11).

## 📂 Repository Structure
- `/surveys`: Digital survey templates and field data collection forms.
- `/data-analysis`: Python scripts/notebooks for processing baseline settlement metrics.
- `/docs`: Official concept notes and framework documentation.
